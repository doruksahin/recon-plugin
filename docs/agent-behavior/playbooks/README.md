# Playbook index

Load one playbook for the current execution stage.

| Task | Playbook |
| --- | --- |
| Turn a real failure into a bounded change and outcome record | [Iterate a Recon behavior](iteration.md) |
| Prove a rail, workflow, user-visible result, or generalization claim | [Demonstrate an outcome](demonstration.md) |

The iteration playbook routes to the demonstration playbook only after the
origin, claim, and interface are frozen. The demonstration playbook does not
authorize external mutations; existing approval boundaries still apply.
